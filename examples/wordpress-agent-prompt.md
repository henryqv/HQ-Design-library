# Example: WordPress design task

Use HQ Design Library before implementing the UI.

Request:

> Create the homepage of a law firm in WordPress.
>
> 1. Search HQ Design Library for legal/editorial design systems.
> 2. Search for hero, services, testimonial and CTA patterns.
> 3. Select a coherent combination rather than copying one reference.
> 4. Translate the design into semantic PHP templates and CSS.
> 5. Use CSS custom properties for tokens.
> 6. Do not introduce React, Tailwind or npm.
> 7. Keep the implementation accessible and responsive.
> 8. If the project has an existing DESIGN.md, treat it as higher priority than HQ references.

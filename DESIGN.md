# Overview

HQ Design Library is a neutral, editorial design knowledge base for AI-assisted web development.

The visual language of the library itself is:

- calm
- structured
- editorial
- accessible
- restrained
- framework agnostic

## Colors

The library UI should use neutral surfaces and a restrained accent.

## Typography

Use a highly readable sans-serif for interface text and a clear hierarchy for documentation.

## Layout

Prefer:

- 8px-based spacing logic
- generous whitespace
- strong alignment
- predictable responsive breakpoints
- content-first layouts

## Components

Components should communicate:

- purpose
- hierarchy
- state
- interaction

## Do's

- Use semantic HTML.
- Prefer explicit tokens.
- Keep patterns composable.
- Make responsive behavior part of the design.

## Don'ts

- Do not assume Tailwind.
- Do not assume React.
- Do not use gradients simply because they are fashionable.
- Do not create excessive rounded cards.
- Do not sacrifice accessibility for visual similarity.
